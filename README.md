# Lactfree

Projeto para ajudar pessoas intolerantes a LACTOSE a controlar o consumo de leite e derivados, quero diminuir o meu consumo e para isso preciso metrificar.

## Funcionalidades

- Criar challenge
- Registrar consumo
- Comprar Comprimido
- Alarme Comprimido
- Alarme de Consumo

## Tecnologias

Angular e .NET 8

## O que quero aprender e exercitar com esse projeto? (Poço do Aprendizado)
- Autenticação e Autorização com JWT e Middleware
- Tratamento robusto de exeções
- Testes de Unidade e Integração de Backend
- Desenvolver via TDD
- Criar uma arquitetura de user case
- Deploy com CI/CD com GitHub Actions
- Organizar o desenvolvimento via Projects do Github
- Utilizar o dockerfile em ambas as partes
- Criar componentes complexos no Angular
- Utilizar RXJS de forma mais aprofundada
- Desenvolvimento de Login e esquecer a senha
- Logar com o Google ou Facebook
- Adição de uma pipeline e analise SAST/DAST no projeto
- Integrar conexão com outras plataformas: email, whatsapp, telegram para enviar os alarmes
- Praticar o SASS do CSS, não utilizar nenhuma biblioteca para sytle(Justamente para praticar melhor meu CSS)
- Criar um Layout bem ousado e enfeitado e definido no FIGMA do ZERO.
- Utilizar ferramentas de IA apenas para auxilio de erros e nada de geração de código
- Adicionar testes de frontend.
- Publicar o site.
- Utilizar o tipo de commits semanticos e escrever em inglês
(E muito mais...)
